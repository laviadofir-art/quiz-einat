## ⚡ פתיחה מקומית (קריטי!)

האתר טוען את השאלות דרך שרת. **לא ניתן לפתוח ישירות כקובץ** (double-click).

### פתרון קל — Python (מובנה במחשב):
1. פתחו טרמינל בתיקיית הפרויקט
2. הריצו: `python3 -m http.server 8000`
3. פתחו בדפדפן: **http://localhost:8000**

### חלופה — VS Code:
התקינו את תוסף **Live Server** ← לחצו ימני על `index.html` ← "Open with Live Server"

## ✏️ הוספת / עריכת שאלות

פתחו את `questions.json`. תמצאו שתי רשימות שאלות:
- `"junior"` — עולה לחטיבת ביניים
- `"senior"` — עולה לחטיבה עליונה

### מבנה שאלה:
```json
{
  "id":          "מזהה_ייחודי",
  "category":    "reading",
  "question":    "טקסט השאלה",
  "options":     ["תשובה א", "תשובה ב", "תשובה ג", "תשובה ד"],
  "correct":     1,
  "explanation": "הסבר שיוצג אחרי הבחירה"
}
```

> **`correct`** = מספר התשובה הנכונה (0 = ראשונה, 1 = שנייה, 2 = שלישית, 3 = רביעית)

### 4 קטגוריות (אל תשנו את המפתח האנגלי!):

| מפתח JSON | שם בעברית | צבע |
|-----------|------------|-----|
| `reading` | הבנת הנקרא | כחול |
| `grammar` | דקדוק | כתום |
| `spelling` | כתיב | ירוק |
| `vocab` | אוצר מילים | סגול |

### מספר שאלות מומלץ:
**5 שאלות לכל קטגוריה** = 20 שאלות סה"כ. ניתן להוסיף יותר — האתר מסתגל אוטומטית.
